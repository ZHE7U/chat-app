# 局域网聊天室 (LAN Chat)

这是一个基于 Node.js、Express 和 WebSocket 构建的一体化局域网聊天室。

## 功能
- 无需复杂配置，一键启动
- 前后端一体化，直接在浏览器中聊天
- 支持局域网内多设备同时在线

## 如何使用
1. 确保电脑安装了 Node.js。
2. 下载或克隆本仓库到本地，在终端运行 `npm install` 安装依赖。
3. 运行 `node server.js` 启动服务。
4. 打开浏览器访问 `http://localhost:3000` 即可开始聊天。
5. 同一个局域网内的其他设备，可以通过 `http://你的局域网IP:3000` 一起加入聊天。
